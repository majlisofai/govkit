# Model provider agreement — summary

Summary of the signed agreement with the hosted model provider (contract register ref. CR-2026-118). The full contract is with Procurement.

| Term | Agreed |
|------|--------|
| Data use | Prompts and outputs are used only to provide the service. No training on bank data. |
| Retention | Zero data retention: prompts and outputs are not stored after the response, except abuse-monitoring metadata for 30 days |
| Location | Processing in the bank's chosen region and its paired failover region |
| Security | Annual SOC 2 Type II report. Notification of security incidents within 24 hours. |
| Model integrity | The provider attests to its model supply-chain controls and notifies material changes to a pinned version |
| Version lifecycle | Pinned versions supported for at least 12 months. 90 days' notice before retirement. |
| IP | The provider indemnifies the bank against third-party IP claims arising from model outputs used as permitted |
| Audit | The bank and its regulator may audit, or rely on the provider's independent reports |
| Exit | Ninety-day exit assistance, and deletion of any bank data on termination |
| Service level | 99.9 % monthly availability, with service credits |
