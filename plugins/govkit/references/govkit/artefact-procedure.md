# GovKit Artefact Procedure

Every GovKit command that writes a `GOV-*` artefact runs these steps around its own content-specific step. The step numbers are referred to from each command as **P1–P8**.

- **P1. Contract.** Read `${CLAUDE_PLUGIN_ROOT}/references/govkit/runtime-contract.md`. Resolve the profile, and the method and framework files the command needs (contract §1–§2).
- **P2. Project.** Find the project from `$ARGUMENTS` (an ID like `001` or a name) by globbing `projects/*/`. If it does not exist and the command is project-scoped, create it with `bash ${CLAUDE_PLUGIN_ROOT}/scripts/bash/create-project.sh --json --name "<name>"`. Organisation-wide types (GMOD, BRPT) use `projects/000-global/`.
- **P3. Inputs.** Read the existing ArcKit (`ARC-*`) and GovKit (`GOV-*`) artefacts the command lists as inputs. If a **required** input is missing, stop. Name the input and the command that produces it, using the ArcKit command whose `doc-type:` matches or the GovKit `command` in `config/doc-types.mjs`. If an **optional** input is missing, note it under the artefact's assumptions.
- **P4. Template.** Use `.govkit/templates-custom/<name>-template.md` if present. Otherwise use `${CLAUDE_PLUGIN_ROOT}/templates/<name>-template.md`.
- **P5. Filename.** Work out the version with `${CLAUDE_PLUGIN_ROOT}/references/version-detection.md`, then run `node ${CLAUDE_PLUGIN_ROOT}/scripts/generate-gov-id.mjs <PID> <TYPE> <VERSION> --relpath` and add `--next-num projects/<dir>/<subdir>` for multi-instance types.
- **P6. Render.** Fill the template. Resolve the Document Control header (contract §4), fill **Profile Basis** from the resolved profile, and replace `[GOVKIT_VERSION]` with GovKit's version. Read it from `${CLAUDE_PLUGIN_ROOT}/.claude-plugin/plugin.json`. Replace `[ARCKIT_VERSION]` with ArcKit's version, located as `/govkit:apply` step 2 describes, or `unknown`. Fill **External References** per `${CLAUDE_PLUGIN_ROOT}/references/citation-instructions.md`. Each framework's `url` and `verified` date go in the Document Register.
- **P7. Check.** Apply the Common Checks in `${CLAUDE_PLUGIN_ROOT}/references/quality-checklist.md` and contract §6. Every rating or status needs an evidence reference. Use no placeholders in the summary sections. Fix any failures before writing.
- **P8. Write and report.** Write with the Write tool to `projects/<dir>/<relpath>`. If GovKit's filename hook blocks the write, use the path it names. Show the user a one-paragraph summary and the counts the command asks for. Do not show the whole document. Then list the command's handoffs.
