# govkit
Governance Kit for AI in regulated institutions

## About

govkit is an opinionated, AI-driven governance toolkit. It is based on
[ArcKit](https://github.com/tractorjuice/arc-kit) (enterprise architecture
governance and vendor procurement), but extends it by combining different
frameworks, methods and tools suited to AI in regulated institutions.

## Status

Early stage. The scope, supported frameworks and tooling are being defined.
